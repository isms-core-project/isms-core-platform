## 連接器的作用

連接器是證據自動化層。每個連接器與外部系統整合——您的雲端供應商、身分平台、弱點掃描器、EDR 或 ITSM 工具——並依排程自動將證據拉取到平台中。

這表示您的合規態勢會持續從真實的基礎設施資料更新，而不僅來自每年一次的手動評鑑。

---

## 連接器儀表板

在側邊欄導覽至 **Evidence → Connectors**。

連接器儀表板會顯示全部 44 個可用連接器及其目前狀態：

| 狀態 | 意義 |
|--------|---------|
| **Active / Healthy** | 連接器已設定、運作中，且上次執行成功 |
| **Active / Warning** | 連接器已設定，但上次執行有非致命問題 |
| **Active / Error** | 連接器已設定，但上次執行失敗——請檢查組態 |
| **Not configured** | 連接器可用，但尚未提供憑證 |

## 設定連接器

連接器設定由平台管理員在 Admin panel 中完成。身為使用者，您可以檢視連接器狀態與已蒐集的證據，但無法修改連接器憑證。

若您需要的連接器顯示「Not configured」或「Error」：
1. 記下連接器名稱與顯示的錯誤訊息
2. 將連接器名稱及所需的憑證或 API 權杖提供給您的平台管理員，與其聯絡

各連接器的憑證要求在 Admin panel 中有說明文件。

---

## 證據重新整理

連接器依管理員設定的排程執行（預設：大多數連接器每 6 小時一次）。上次執行的時間戳記與狀態會顯示在連接器卡片上。

若您需要立即取得最新證據——例如在稽核查核之前——管理員可從 **Admin → Connectors → Run now** 觸發手動連接器執行。

---

## 雙向：Jira 與 ServiceNow

Jira 與 ServiceNow 是兩個雙向連接器。除了向內拉取證據，它們也支援向外為缺口與矯正行動建立工單。

關於如何將缺口推送至 Jira 或 ServiceNow，請見[缺口管理](08-gap-management.zh-TW.md)。
