## 连接器的作用

连接器是证据自动化层。每个连接器与外部系统整合——您的云端供应商、身分平台、漏洞扫描器、EDR 或 ITSM 工具——并依计划自动将证据拉取到平台中。

这表示您的合规态势会持续从真实的基础设施数据更新，而不仅来自每年一次的手动评估。

---

## 连接器仪表板

在侧边栏导览至 **Evidence → Connectors**。

连接器仪表板会显示全部 44 个可用连接器及其目前状态：

| 状态 | 意义 |
|--------|---------|
| **Active / Healthy** | 连接器已设置、运作中，且上次执行成功 |
| **Active / Warning** | 连接器已设置，但上次执行有非致命问题 |
| **Active / Error** | 连接器已设置，但上次执行失败——请检查配置 |
| **Not configured** | 连接器可用，但尚未提供凭证 |

## 设置连接器

连接器设置由平台管理员在 Admin panel 中完成。身为用户，您可以检视连接器状态与已搜集的证据，但无法修改连接器凭证。

若您需要的连接器显示「Not configured」或「Error」：
1. 记下连接器名称与显示的错误消息
2. 将连接器名称及所需的凭证或 API 令牌提供给您的平台管理员，与其联系

各连接器的凭证要求在 Admin panel 中有说明文件。

---

## 证据重新整理

连接器依管理员设置的计划执行（预设：大多数连接器每 6 小时一次）。上次执行的时间戳记与状态会显示在连接器卡片上。

若您需要立即取得最新证据——例如在审计查核之前——管理员可从 **Admin → Connectors → Run now** 触发手动连接器执行。

---

## 双向：Jira 与 ServiceNow

Jira 与 ServiceNow 是两个双向连接器。除了向内拉取证据，它们也支持向外为缺口与矫正行动建立工单。

关于如何将缺口推送至 Jira 或 ServiceNow，请见[缺口管理](08-gap-management.zh-CN.md)。
