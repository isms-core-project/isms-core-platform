## 什麼是 ISMS CORE 平台？

ISMS CORE 平台是一套適用於 ISO 27001:2022 及其延伸標準的合規管理系統。它把 ISMS CORE 內容工廠產出的政策、實施指引與評鑑工作簿，轉化為一套實際運作中的系統——可搜尋、可評分、與證據連結，並透過自動化連接器持續更新。

本平台不會取代你的 ISMS。它*就是*你的 ISMS——你在這裡管理控制措施、追蹤缺口、蒐集證據、對多個框架評鑑合規，並在任何一天展示稽核準備度。

---

## 本平台不是什麼

**它不是文件產生器。** 政策與實施指引由資訊安全從業人員撰寫，並以內容形式載入平台。你在這裡閱讀、自訂與追蹤它們——而不是在這裡產生它們。

**它不是工單系統。** 它整合 Jira 與 ServiceNow 來達成該用途。

**它不是 SIEM。** 它整合你的 SIEM 作為證據來源。

**它不是一次性的稽核工具。** 它是為持續合規管理而設計——而非衝刺一次就遺忘。

## 五項產品

本平台承載五個產品家族，各自涵蓋不同的 ISO 標準。你可以依組織範圍啟用其中一個或全部五個。

### ISMS Framework

核心產品。涵蓋全部 54 個 ISO 27001:2022 附錄 A 控制群組及完整說明文件：政策（POL）、給使用者（IMP-UG）與技術團隊（IMP-TG）的實施指引、自評計分卡（SCR）與評鑑工作簿（WKBK）。提供 EN、FR、DE 與 IT 版本。

### ISMS Operational

給較小型組織、或需要更快達成 ISO 27001 準備度者的輕量政策集。53 份營運政策（OP-POL）搭配自評檢核表。採用與 Framework 相同的控制結構，但說明文件更精簡。

### Privacy 延伸套件（ISO 27701:2025）

21 個控制群組，涵蓋 ISO 27701:2025 隱私資訊管理系統延伸。分為控管者、處理者與共用控制措施。設計用意是補充 ISMS Framework——而非取代它。

### Cloud 延伸套件（ISO 27018:2025）

12 個控制群組，涵蓋 ISO 27018:2025 下公有雲環境中的 PII 保護。適用於任何使用 IaaS、PaaS 或 SaaS 雲端服務處理個人資料的組織。

### AI 延伸套件（ISO 42001:2023 + ISO 42005:2025）

10 個控制群組，涵蓋 AI 管理系統標準（ISO 42001:2023），並整合 ISO 42005:2025 的 AI 風險評鑑內容。涵蓋 AI 系統清冊、風險管理、衝擊評鑑、透明度、人工監督與供應商 AI 治理。

## 本平台如何融入你的 ISMS 生命週期

```
設計              →  控制措施庫、專案工作區
實作              →  政策、實施指引、文件編輯器
評鑑              →  評鑑檢核表、23 個合規框架
監控              →  證據連接器、KPI 儀表板、威脅情報
審查              →  缺口管理、風險登錄表、EBIOS RM
改善              →  補救追蹤、TPRM、BIA
稽核              →  QA 引擎、跨框架對應、報告與匯出
```

ISO 27001 規劃—執行—檢查—行動（Plan-Do-Check-Act）循環的每個階段，都有對應的平台能力。

## 內容如何進入平台

內容由平台管理員使用啟動腳本或管理員匯入面板載入。載入後，具備適當權限的所有使用者皆可使用。你不需要自行上傳或設定內容——它已預先結構化，可直接使用。

當管理員更新平台時（例如發布新的控制措施版本或翻譯），他們會重新執行匯入。既有工作——你的專案文件、缺口紀錄、證據、評鑑——都會保留。

## 支援的語言

政策與實施文件提供以下語言：

- **English (EN)**——全部五項產品
- **French (FR)**——全部五項產品
- **German (DE)**——全部五項產品
- **Italian (IT)**——全部五項產品

## 國家在地化

ISMS CORE 內建感知司法管轄區的政策呈現。當組織的國家已設定，法規參照、資料保護主管機關名稱與相關法規會自動替換進政策文件，以反映你的司法管轄區。

支援的司法管轄區：瑞士（預設）、奧地利、比利時、法國、德國、義大利、盧森堡、英國。

這由管理員在 **Admin → Organisation** 中設定。
