## 登入

在瀏覽器前往你的平台網址。若看到憑證警告（「你的連線不是私人連線」），這在使用自簽憑證的內部部署中是預期現象。接受警告以繼續——連線仍經過加密。

輸入你的電子郵件地址與密碼。若你已啟用多重要素驗證（MFA），在輸入密碼後系統會提示你輸入 6 位數的 TOTP 驗證碼。

> 你的初始密碼與角色由管理員設定。若無法登入或忘記憑證，請聯絡他們。

## 儀表板

登入後，你會進入 **Home dashboard**。這是目前作用中產品的營運概觀。

### 情報卡片

儀表板頂端有四張情報卡片，顯示你威脅饋送資料的目前狀態：

- **CVE Index**——從 NVD 饋送索引的 CVE 總數
- **CISA KEV**——追蹤的已知遭利用弱點總數
- **MITRE ATT&CK**——上次饋送更新時間戳
- **Feed Health**——所有威脅情報饋送的整體狀態

點選任一卡片即可前往 **Threat Intelligence** 區段。

### 合規指標

情報卡片下方，儀表板會顯示目前作用中產品家族的合規指標：

- 控制群組總數與涵蓋百分比
- 政策狀態摘要（imported、draft、approved、published）
- 評鑑完整度
- 未結缺口數量
- 證據新鮮度指標
- 稽核準備度分數

### 健康警示橫幅

若過去 24 小時內有任何饋送執行、連接器同步或 OpenSearch 檢查回報錯誤，頁面頂端會出現可關閉的琥珀色橫幅。這純粹是提示資訊——平台仍會繼續運作。點選橫幅或前往 **Intelligence** 區段以進一步調查。

## 導覽

### 側邊欄

左側邊欄是你的主要導覽。它可收合為僅有圖示的窄條——點選底部的箭頭即可切換。在收合模式下將游標移到任一圖示上，會顯示含區段名稱的工具提示。

側邊欄依群組編排：

| 群組 | 包含內容 |
|-------|-----------------|
| **ISMS** | 控制措施庫、概觀、政策、涵蓋範圍、產生器工作簿 |
| **Projects** | 專案工作區 |
| **Compliance** | 評鑑檢核表、全部 23 個框架評鑑頁面 |
| **Risk & Operations** | 風險登錄表、缺口管理、EBIOS RM、BIA、TPRM |
| **Evidence** | 證據追蹤器、連接器 |
| **Intelligence** | MITRE ATT&CK、CVE/CPE 探索器、KEV 稽核 |
| **Analytics** | KPI 儀表板、跨框架對應 |
| **Tools** | QA 引擎、ISMS Compass、自訂框架 |
| **Global** | 所有框架評鑑頁面（NIS2、DORA、NIST CSF 2.0 等） |
| **Admin** | 使用者管理、系統設定、匯入面板（僅限 Admin 角色） |

### 產品切換器

產品切換器出現在側邊欄 ISMS 群組的頂端（或在感知產品的頁面上以分頁選擇器呈現）。用它切換於下列之間：

- **ISMS**——Framework 與 Operational 內容
- **Privacy**——ISO 27701:2025 內容
- **Cloud**——ISO 27018:2025 內容
- **AI**——ISO 42001:2023 內容

切換產品會改變控制措施庫、政策、涵蓋範圍與評鑑頁面顯示的脈絡。框架層級的工具（風險登錄表、缺口管理、證據等）並非特定於產品——它們涵蓋你完整的 ISMS 範圍。

## 你的作用中專案

平台中大多數合規工作都在 **Project** 內進行。專案是一個具名的工作區，擁有一組精選的內容庫子集——與特定範圍、稽核週期或組織單位相關的政策、實作、評鑑、缺口與證據。

**active project** 會以彩色標籤顯示在側邊欄產品切換器下方。你隨時可以從專案工作區切換作用中專案。

若沒有作用中的專案，你是在全域內容庫檢視中工作——你可以瀏覽所有內容，但無法編輯或追蹤項目。

> **建議的第一步：** 請管理員為你的組織建立專案；若你具備 ISMS 經理角色，也可以自行建立（參閱[專案工作區](04-projects-workspace.zh-TW.md)）。

## 使用者角色與你能做的事

你的角色決定你在平台中能看到與能做的事。

| 角色 | 能力 |
|------|-------------|
| **Super Admin** | 跨組織存取——管理組織與使用者、檢視組合指標 |
| **Admin** | 組織內的完整存取權——使用者管理、匯入、系統設定 |
| **ISMS Manager** | 所有合規工作：控制措施、評鑑、缺口、證據、專案、風險 |
| **Auditor** | 可唯讀存取一切。可執行匯出與 QA 檢查。 |
| **Control Owner** | 僅對獲指派的控制群組有讀寫權 |
| **Viewer** | 對非機密內容唯讀 |

若你需要目前角色無法使用的某項能力，請聯絡管理員。

## 個人檔案與 MFA

點選畫面右上角的姓名或頭像以存取個人檔案（或前往 **System → MFA Setup**）。

### 變更密碼

前往 **Admin → Users**，找到你的帳戶，並使用編輯動作更新密碼。

### 設定 MFA

強烈建議所有使用者啟用雙因素驗證；Admin 及以上角色則必須啟用。

1. 前往 **System → MFA Setup**
2. 使用 Google Authenticator、Authy 或任何 TOTP 應用程式掃描 QR 碼
3. 輸入 6 位數驗證碼以確認設定
4. 儲存顯示的 8 組備用碼——這些是一次性的復原碼，供你手邊沒有驗證器裝置時使用

啟用後，每次登入都會提示你輸入 TOTP 驗證碼。
