## 什么是 ISMS CORE 平台？

ISMS CORE 平台是一套适用于 ISO 27001:2022 及其延伸标准的合规管理系统。它把 ISMS CORE 内容工厂产出的政策、实施指南与评估工作簿，转化为一套实际运作中的系统——可搜寻、可评分、与证据连结，并透过自动化连接器持续更新。

本平台不会取代你的 ISMS。它*就是*你的 ISMS——你在这里管理控制措施、追踪缺口、搜集证据、对多个框架评估合规，并在任何一天展示审计准备度。

---

## 本平台不是什么

**它不是文件生成器。** 政策与实施指南由信息安全从业人员撰写，并以内容形式载入平台。你在这里阅读、自定义与追踪它们——而不是在这里产生它们。

**它不是工单系统。** 它整合 Jira 与 ServiceNow 来达成该用途。

**它不是 SIEM。** 它整合你的 SIEM 作为证据来源。

**它不是一次性的审计工具。** 它是为持续合规管理而设计——而非冲刺一次就遗忘。

## 五项产品

本平台承载五个产品家族，各自涵盖不同的 ISO 标准。你可以依组织范围启用其中一个或全部五个。

### ISMS Framework

核心产品。涵盖全部 54 个 ISO 27001:2022 附录 A 控制群组及完整说明文件：政策（POL）、给用户（IMP-UG）与技术团队（IMP-TG）的实施指南、自评计分卡（SCR）与评估工作簿（WKBK）。提供 EN、FR、DE 与 IT 版本。

### ISMS Operational

给较小型组织、或需要更快达成 ISO 27001 准备度者的轻量政策集。53 份运营政策（OP-POL）搭配自评检查表。采用与 Framework 相同的控制结构，但说明文件更精简。

### Privacy 延伸套件（ISO 27701:2025）

21 个控制群组，涵盖 ISO 27701:2025 隐私信息管理系统延伸。分为控管者、处理者与共用控制措施。设计用意是补充 ISMS Framework——而非取代它。

### Cloud 延伸套件（ISO 27018:2025）

12 个控制群组，涵盖 ISO 27018:2025 下公有云环境中的 PII 保护。适用于任何使用 IaaS、PaaS 或 SaaS 云端服务处理个人数据的组织。

### AI 延伸套件（ISO 42001:2023 + ISO 42005:2025）

10 个控制群组，涵盖 AI 管理系统标准（ISO 42001:2023），并整合 ISO 42005:2025 的 AI 风险评估内容。涵盖 AI 系统清册、风险管理、影响评估、透明度、人工监督与供应商 AI 治理。

## 本平台如何融入你的 ISMS 生命周期

```
设计              →  控制措施库、项目工作区
实作              →  政策、实施指南、文件编辑器
评估              →  评估检查表、23 个合规框架
监控              →  证据连接器、KPI 仪表板、威胁情报
审查              →  缺口管理、风险登录表、EBIOS RM
改善              →  补救追踪、TPRM、BIA
审计              →  QA 引擎、跨框架对应、报告与导出
```

ISO 27001 规划—执行—检查—行动（Plan-Do-Check-Act）循环的每个阶段，都有对应的平台能力。

## 内容如何进入平台

内容由平台管理员使用启动脚本或管理员导入面板载入。载入后，具备适当权限的所有用户皆可使用。你不需要自行上传或设置内容——它已预先结构化，可直接使用。

当管理员更新平台时（例如发布新的控制措施版本或翻译），他们会重新执行导入。既有工作——你的项目文件、缺口记录、证据、评估——都会保留。

## 支持的语言

政策与实施文件提供以下语言：

- **English (EN)**——全部五项产品
- **French (FR)**——全部五项产品
- **German (DE)**——全部五项产品
- **Italian (IT)**——全部五项产品

平台介面为英文。文件语言在导入时依产品设置，并依载入状态显示。

## 国家在地化

ISMS CORE 内建感知司法管辖区的政策呈现。当组织的国家已设置，法规参照、数据保护主管机关名称与相关法规会自动替换进政策文件，以反映你的司法管辖区。

支持的司法管辖区：瑞士（预设）、奥地利、比利时、法国、德国、义大利、卢森堡、英国。

这由管理员在 **Admin → Organisation** 中设置。
