## 什么是项目？

**Project** 是一个具名的工作区，拥有一组精选的政策、实施指南、评估、缺口与证据。它是你 ISMS 的运营单位——你每天处理的一切都在项目内进行。

典型的项目：

- 你的主要 ISO 27001 验证范围
- 特定的审计周期（例如「2026 年监督审计」）
- 具有自身范围的组织单位或子公司
- 为 ISO 27701 工作而设的隐私项目

前往侧边栏的 **Projects** 以查看你的项目清单并建立新项目。

---

## 建立项目

1. 点选 **New Project**
2. 输入项目名称与选填的描述
3. 选择产品家族（ISMS、Privacy、Cloud、AI——或全部）
4. 设置文件变数（见下文）——这些会自动套用到你加入项目的所有文件
5. 点选 **Create**

新项目会出现在你的项目清单中。点选它以开启项目工作区，并将其设为你的作用中项目。

---

## 文件变数

文件变数是组织专属的令牌，当你把政策文件加入项目时，它们会被替换进文件中。这就是泛用的「Organisation Name shall...」自动变成「Bamboo Tech AG shall...」的方式。

常见的变数包括：

| 变数 | 范例 |
|----------|---------|
| 组织名称 | Bamboo Tech AG |
| CISO / RSSI 姓名 | Jane Smith |
| DPO 姓名 | Marc Dupont |
| 生效日期 | 2026-05-01 |
| 审查日期 | 2027-05-01 |
| 文件所有者 | Information Security Team |

变数在建立项目时设置，并可在 **Project Settings** 中更新。更新后，你可以将它们批次重新套用到项目中的所有文件。

## 新增内容到项目

### 新增政策

1. 开启你的项目并前往 **Policies** 分页
2. 点选 **Add from Library**
3. 浏览或搜寻你想要的政策文件
4. 选取一或多份文件并点选 **Add**

新增政策时，会自动套用文件变数替换——平台会将文件中的所有变数令牌替换为你的项目值。

### 新增实作

前往 **Implementations** 分页并使用相同的 Add from Library 流程。IMP-UG（面向用户）与 IMP-TG（技术性）文件会分开列出。

### 批次动作

在 Policies 或 Implementations 分页中，使用核取方块栏选取多份文件并执行批次动作：

- **Apply variables**——重新替换文件变数（在更新项目变数后使用）
- **Change status**——将选取的文件移至 draft、review、approved 或 published
- **Move to bin**——将选取的文件软删除（可予以还原）

## 文件编辑器

点选项目中的任一文件以开启 **Document Editor**。编辑器有两种模式：

### WYSIWYG 模式（预设）

由 TipTap v3 驱动的富文本编辑器。你可以：

- 直接编辑文本——使用格式化工具列设置标题、粗体、斜体、清单与表格
- 新增与编辑表格（格状表格在储存时会自动转换为 GitHub Flavored Markdown）
- 插入图片（拖放或贴上）

你的变更会自动储存。文件会保留其原始结构——只有你改动的内容会被修改。

### 原始码模式

点选 **Source** 切换钮以切换至原始 Markdown 编辑。这对于精确格式化或批次文本变更很有用。你随时可以切回 WYSIWYG——平台会正确地呈现你的 Markdown。

> 中继数据注解区块（水印）会自动从编辑检视中移除，以免干扰文件内容。它们会保留在储存的文件中。

## 文件生命周期（批准流程）

项目中的每份文件都有一个生命周期状态：

| 状态 | 意义 |
|-------|---------|
| **Draft** | 进行中——尚未批准 |
| **Review** | 已提交给 ISMS 经理或 Admin 审查 |
| **Approved** | 已审查并批准——可发布 |
| **Published** | 作用中——目前使用中的版本 |

审计人员可以看到所有状态。就合规评分而言，只有已发布的文件才被视为「作用中」。

使用文件编辑器中的 **Status** 下拉列表，或透过政策清单中的批次动作来变更文件状态。

## SCR 检查表

项目中的每份政策都有一个对应的 **SCR**（自评检查表）。文件检视中的 SCR 分页会显示该控制群组的检查表项目。

对每个项目：

1. 设置 **status**——Compliant、Partial、Non-compliant、Not applicable
2. 新增 **comment**，描述你的证据或理由
3. 将证据项目直接**连结**至检查表项目

完整度评分（已设置状态的检查表项目百分比）会以进度列显示在 SCR 分页上，并纳入项目的整体合规分数。

---

## 项目完整度分数

项目概览页面会显示整体完整度分数——以下项目的加权摘要：

- 政策文件涵盖率（已新增的预期政策百分比）
- 评估完成度（已设置状态的 SCR 项目百分比）
- 证据附加率（至少有一项证据的检查表项目百分比）

这是你的主要「我们准备好接受审计了吗？」的概览指标。

---

## 资源回收筒与还原

移至资源回收筒的文件会被软删除——它们不会出现在项目检视中，但不会被永久移除。若要还原：

1. 前往 **Project Settings → Bin**
2. 选取要还原的文件
3. 点选 **Restore**

永久删除可从资源回收筒检视执行，且需要 Admin 或 ISMS 经理角色。

---

## 切换作用中项目

一次只能有一个作用中的项目。风险情境、缺口与证据项目都以作用中项目为范围——切换项目即切换你的工作脉络。

若要切换：

1. 点选侧边栏中的作用中项目标签
2. 从清单中选取你想要的项目

或前往 **Projects**，在任何项目上点选 **Set Active**。
