## 登录

在浏览器前往你的平台网址。若看到凭证警告（「你的连线不是私人连线」），这在使用自签凭证的内部部署中是预期现象。接受警告以继续——连线仍经过加密。

输入你的电子邮件地址与密码。若你已启用多重要素验证（MFA），在输入密码后系统会提示你输入 6 位数的 TOTP 验证码。

> 你的初始密码与角色由管理员设置。若无法登录或忘记凭证，请联系他们。

## 仪表板

登录后，你会进入 **Home dashboard**。这是目前作用中产品的运营概览。

### 情报卡片

仪表板顶端有四张情报卡片，显示你威胁馈送数据的目前状态：

- **CVE Index**——从 NVD 馈送索引的 CVE 总数
- **CISA KEV**——追踪的已知遭利用漏洞总数
- **MITRE ATT&CK**——上次馈送更新时间戳
- **Feed Health**——所有威胁情报馈送的整体状态

点选任一卡片即可前往 **Threat Intelligence** 区段。

### 合规指标

情报卡片下方，仪表板会显示目前作用中产品家族的合规指标：

- 控制群组总数与涵盖百分比
- 政策状态摘要（imported、draft、approved、published）
- 评估完整度
- 未结缺口数量
- 证据新鲜度指标
- 审计准备度分数

### 健康警示横幅

若过去 24 小时内有任何馈送执行、连接器同步或 OpenSearch 检查回报错误，页面顶端会出现可关闭的琥珀色横幅。这纯粹是提示信息——平台仍会继续运作。点选横幅或前往 **Intelligence** 区段以进一步调查。

## 导览

### 侧边栏

左侧边栏是你的主要导览。它可收合为仅有图示的窄条——点选底部的箭头即可切换。在收合模式下将游标移到任一图示上，会显示含区段名称的工具提示。

侧边栏依群组编排：

| 群组 | 包含内容 |
|-------|-----------------|
| **ISMS** | 控制措施库、概览、政策、涵盖范围、生成器工作簿 |
| **Projects** | 项目工作区 |
| **Compliance** | 评估检查表、全部 23 个框架评估页面 |
| **Risk & Operations** | 风险登录表、缺口管理、EBIOS RM、BIA、TPRM |
| **Evidence** | 证据追踪器、连接器 |
| **Intelligence** | MITRE ATT&CK、CVE/CPE 探索器、KEV 审计 |
| **Analytics** | KPI 仪表板、跨框架对应 |
| **Tools** | QA 引擎、ISMS Compass、自定义框架 |
| **Global** | 所有框架评估页面（NIS2、DORA、NIST CSF 2.0 等） |
| **Admin** | 用户管理、系统设置、导入面板（仅限 Admin 角色） |

### 产品切换器

产品切换器出现在侧边栏 ISMS 群组的顶端（或在感知产品的页面上以分页选择器呈现）。用它切换于下列之间：

- **ISMS**——Framework 与 Operational 内容
- **Privacy**——ISO 27701:2025 内容
- **Cloud**——ISO 27018:2025 内容
- **AI**——ISO 42001:2023 内容

切换产品会改变控制措施库、政策、涵盖范围与评估页面显示的脉络。框架层级的工具（风险登录表、缺口管理、证据等）并非特定于产品——它们涵盖你完整的 ISMS 范围。

## 你的作用中项目

平台中大多数合规工作都在 **Project** 内进行。项目是一个具名的工作区，拥有一组精选的内容库子集——与特定范围、审计周期或组织单位相关的政策、实作、评估、缺口与证据。

**active project** 会以彩色标签显示在侧边栏产品切换器下方。你随时可以从项目工作区切换作用中项目。

若没有作用中的项目，你是在全域内容库检视中工作——你可以浏览所有内容，但无法编辑或追踪项目。

> **建议的第一步：** 请管理员为你的组织建立项目；若你具备 ISMS 经理角色，也可以自行建立（参阅[项目工作区](04-projects-workspace.zh-CN.md)）。

## 用户角色与你能做的事

你的角色决定你在平台中能看到与能做的事。

| 角色 | 能力 |
|------|-------------|
| **Super Admin** | 跨组织访问——管理组织与用户、检视组合指标 |
| **Admin** | 组织内的完整访问权——用户管理、导入、系统设置 |
| **ISMS Manager** | 所有合规工作：控制措施、评估、缺口、证据、项目、风险 |
| **Auditor** | 可唯读访问一切。可执行导出与 QA 检查。 |
| **Control Owner** | 仅对获指派的控制群组有读写权 |
| **Viewer** | 对非机密内容唯读 |

若你需要目前角色无法使用的某项能力，请联系管理员。

## 个人档案与 MFA

点选画面右上角的姓名或头像以访问个人档案（或前往 **System → MFA Setup**）。

### 变更密码

前往 **Admin → Users**，找到你的账户，并使用编辑动作更新密码。

### 设置 MFA

强烈建议所有用户启用双因素验证；Admin 及以上角色则必须启用。

1. 前往 **System → MFA Setup**
2. 使用 Google Authenticator、Authy 或任何 TOTP 应用程序扫描 QR 码
3. 输入 6 位数验证码以确认设置
4. 储存显示的 8 组备用码——这些是一次性的恢复码，供你手边没有验证器装置时使用

启用后，每次登录都会提示你输入 TOTP 验证码。
