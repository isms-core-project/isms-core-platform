## 概览

平台包含 29 个合规架构评估模块。这些涵盖法规义务、业界标准与特定产业要求，是推行 ISO 27001 ISMS 的组织在 ISO 认证之外，通常也需要证明遵循的部分。

架构评估是全域性的——它们不绑定于特定项目，而是涵盖您组织整体的合规态势。

从侧边栏的 **Compliance** 区段，或侧边栏底部的 **Global** 群组，导览至任一架构。

## 使用架构评估

全部 29 个架构的体验一致。

### 开启评估

从侧边栏导览至该架构页面。页面会显示：

- 架构中介数据（标准编号、版本、发布机构）
- 整体合规分数与完成百分比
- 依章节／领域／功能分组的评估项目

### 评分项目

每个项目都有成熟度量表：

| 分数 | 标签 | 意义 |
|-------|-------|---------|
| 0 | Not implemented | 未采取任何措施 |
| 1 | Initial | 临时性，未系统化实作 |
| 2 | Managed | 已实作但未正式管理 |
| 3 | Defined | 已正式文件化并实作 |
| 4 | Optimising | 持续监控与改善 |

对于二元架构（CSRM），项目为：Met / Partial / Not Met / Exception。

设置分数、新增备注，并可选择性连结至证据项目。变更会自动储存。

### NIST CSF 2.0——特殊功能

NIST CSF 2.0 模块具备额外能力：

- **分级设置档评估**——将 106 项子类别各评为等级 1–4
- **雷达图报告**——以视觉化呈现逐功能评分
- **XLSX 导入**——从官方 NIST CSF 2.0 Excel 模板导入分数
- **XLSX/CSV 导出**——以试算表格式导出您的分数

### BSI IT-Grundschutz——特殊功能

BSI 模块同时对应三项 ISO 标准。对照检视器会显示哪些模块对应至哪些 ISO 27001、ISO 27701 与 ISO 27018 控制措施——对同时推行 ISO + BSI 计划的组织很有用。

## 评估集合

将架构评估群组为具名集合以便报告。一个集合可包含来自多个架构的评估——例如将您的 NIS2、DORA 与 ISO 27001 评估合并为单一份「Regulatory Compliance Package」报告。

关于如何建立与导出集合，请见[合规评估 → 评估集合](06-compliance-assessments.zh-CN.md#评估集合)。

---

## 跨架构推断涵盖范围

当您完成 ISO 27001 架构评估后，平台会使用内建的对照映射自动推断 NIS2、DORA 与 GDPR 的涵盖范围。这表示您不需要手动重复 ISO 27001 的评估工作，就能取得初步的 NIS2 或 DORA 分数。

详见[跨架构映射](15-cross-framework-mapping.zh-CN.md)。
