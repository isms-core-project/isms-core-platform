## 🎯 什么是 ISMS CORE？

ISMS CORE 是一套生产等级的**控制工程**平台，用来建置与运营信息安全管理系统。它把合规实施当成**工程问题**处理，而不是顾问作业。

> **第一次接触？** 请先读 [PARADIGM.zh-CN.md](PARADIGM.zh-CN.md) — 它描述 ISMS CORE 与传统 ISMS 做法的差异、如何在各产品之间选择，以及可以预期什么。

> **范例工作流程 — A.8.24 密码学的使用：**
> 1. 打开 `POL/` → 组织的密码学政策，签核后即可发布
> 2. 打开 `IMP/IMP-UG/` → 如何推动密钥管理计划（KPI、评审周期、权责归属）
> 3. 打开 `IMP/IMP-TG/` → TLS 配置、凭证生命周期、HSM 建置、厂商注意事项
> 4. 执行 `SCR/generate_a824_*.py` → 产出 `.xlsx` 评鉴工作簿
> 5. 把工作簿交给审计人员，作为结构化的合规证据

**产生器的前置条件：** Python 3.11+、`pip install openpyxl`

## 🧭 适合谁（与不适合谁）

**适合：**
- 正在建置 ISMS、想要**可重复、可审计证据**的安全团队
- 偏好**自动化＋测试**、不要「安全表演」的工程师
- 需要**实用、可审计政策**、不想过度工程化的中小企业
- 处理 PII、需要 **ISO 27701 控管者／处理者控制措施**的组织
- 需要 **ISO 27018 PII 合规**或 **ISO 27017 云端安全控制措施**的云端服务供应商
- 开发 AI 系统、需要 **ISO 42001 AIMS 治理**的组织
- 需要**结构化、可追溯控制套件**的顾问与审计人员

**不适合：**
- 期待「一键合规」的人
- 需要 GDPR／DORA／NIS2 法律解释的场合（请咨询律师）
- 执行自己没读过的脚本（请把它当程式码看待）

## 🚀 快速开始

**前置条件：** Python 3.11+、`pip install openpyxl`

### 框架版 — ISO 27001:2022 完整工程

```bash
# 浏览 53 个控制套件
cat isms-core-framework/CONTROLS.md

# 进入某一项控制措施，依序读 POL → IMP-UG → IMP-TG，然后产出工作簿
cd isms-core-framework/A.8-technological-controls/isms-a.8.24-use-of-cryptography/SCR
python3 generate_a824_1_data_transmission_assessment.py
```

### 运营版 — ISO 27001:2022 中小企业版

```bash
cd isms-core-operational/A.5-organisational-controls/isms-a.5.1-2-information-security-policies/SCR
python3 generate_op_checklist_a512.py
```

### 隐私 — ISO 27701:2025

```bash
cd isms-core-privacy/privacy-controller/priv-a.1.2.2-5-lawful-basis-and-consent/SCR
python3 generate_priv_checklist_a1225.py
```

### 云端 PII — ISO 27018:2025

```bash
cd isms-core-cloud/iso27018-pii-cloud/cld-a.11-information-security/SCR
python3 generate_cld_checklist_a11.py
```

### 云端安全 — ISO 27017:2026

```bash
cd isms-core-cloud/iso27017-sec-cloud/cld-sec-a.5.38-shared-roles-responsibilities/SCR
python3 generate_cld_sec_checklist_a538.py
```

### AI — ISO 42001:2023

```bash
# 从 AI 治理基础政策开始（提供 EN、FR、DE、IT 版本）
cat "isms-core-ai/00-ai-foundation-policies/ai-pol-01-aims-governance-and-decision-making/POL/AI-POL-01 - AIMS Governance and Decision-Making Framework.md"
```

### 平台 — 可运作的合规仪表板

```bash
cd isms-core-platform
cp .env.example .env         # 填入 HOST_IP、密码、ADMIN_PASSWORD
docker compose up -d             # COMPOSE_PROFILES=opensearch-single 已在 .env.example 设定
bash bootstrap.sh            # 一键完成：建立所有控制群组、汇入所有内容
# → 开启 https://{HOST_IP}
```

完整部署指南、TLS 选项、连接器设定与上线检核表，请见 [PLATFORM.zh-CN.md](PLATFORM.zh-CN.md)。

## 🔒 安全

- **漏洞通报：** 安全问题请寄至 **info@isms-core.com**（主旨：「ISMS CORE Security」）
- **安全使用：** 执行前先阅读脚本。请在虚拟环境中执行。在证明并非如此之前，请把产出的成品当作机密数据处理。
- **不要放机密：** 请勿把凭证、权杖、私密密钥或客户数据提交到本储存库或产出的工作簿中。
