## 本指南目的

本指南提供在 ISO/IEC 27017:2026 条款 5.38 之下，将共同信息安全角色与职责予以文件化所需的**技术结构、纲要与模板**。内容涵盖：

- 共同责任矩阵纲要（CSC 与 CSP 两种角色均使用）
- 面向 CSC 的能力说明文件模板（CSP 角色）
- 责任分配缺口记录纲要

**适用对象**：CISO、云端安全经理、云端工程。

---

## 1. 共同责任矩阵纲要

每一段云端服务关系建立一份矩阵。由云端安全经理维护。

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `service_id` | 字符串（唯一） | 内部参照：`CSV-YYYY-NNN` |
| `service_name` | 字符串 | 云端服务的名称 |
| `counterparty_name` | 字符串 | CSP 的名称（若[组织]为 CSC）或 CSC 的名称（若[组织]为 CSP） |
| `organisation_role` | 枚举 | CSC／CSP／两者 |
| `service_model` | 枚举 | IaaS／PaaS／SaaS |
| `shared_responsibility_model_ref` | 字符串 | 所依据之已发布共同责任模型的参照／版本 |
| `responsibility_area` | 字符串 | 例如「身份验证」、「密码学」、「备份」、「日志」、「修补」、「网络分段」 |
| `allocated_to` | 枚举 | CSC／CSP／共同 |
| `csc_action_required` | 文本 | CSC 为履行其负责部分所须采取的行动（若为共同或分配予 CSC） |
| `csp_action_required` | 文本 | CSP 为履行其负责部分所须采取的行动（若为共同或分配予 CSP） |
| `fulfilment_confirmed` | 布尔值 | [组织]是否已确认其能够／确实履行所分配的部分 |
| `last_reviewed_date` | 日期 | 此责任领域上次审查的日期 |
| `next_review_date` | 日期 | 下次排定审查的日期 |
| `notes` | 文本 | 例外、补偿性控制措施或升级通报参照 |

## 3. 责任分配缺口记录纲要

记录共同责任矩阵中发现的任何缺口及其处理结果。

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `gap_id` | 字符串（唯一） | 内部参照：`ARG-YYYY-NNN` |
| `service_id` | 字符串 | 共同责任矩阵项目的参照 |
| `identified_date` | 日期 | 发现缺口的日期 |
| `identified_by` | 字符串 | 发现缺口者的姓名／角色 |
| `gap_description` | 文本 | 未分配或无法履行之责任的描述 |
| `identification_source` | 枚举 | 上线审查／年度审查／事件／CSP 或 CSC 通知 |
| `escalated_to_ciso` | 布尔值 | 是否已升级通报至 CISO |
| `resolution_type` | 枚举 | 补偿性控制措施／合同修订／重新评估服务／接受风险 |
| `resolution_description` | 文本 | 缺口如何处理的描述 |
| `resolution_date` | 日期 | 缺口结案的日期 |
| `signed_off_by` | 字符串 | 批准结案者的姓名／角色 |
